## 技术参数对照
1 服务载体：首页左侧手机——公众号菜单「名医温州」/ 小程序宫格入口
2–13 居民端：登录注册（手机号/身份证+密码、验证码、注册实名、找回密码）、预约列表、医生搜索、医生信息、分享（海报二维码/微信好友/保存图片/复制链接）、关注、安排医生（预约意向）、留言板、优化意见、预约挂号、预约记录（取消/改约/全流程追踪）、消息通知（健康温州消息 + 短信）
14/15/17 机构端：登录（含验证码）、按坐诊医院/坐诊医生/患者姓名等统计查询、留言内容批量导出（CSV）、名医预约需求处理、停诊通知
16 管理后台：各地名医汇介绍信息维护、机构/名医档案、号源池维护、优化意见回复、账号配置、三方接口联调与日志
18–20 接口服务：号源池维护（号源/停诊/号源类别字典）、三方服务（消息平台/短信/号源池/HIS/公安核验，模拟）
23 第三方调用接口：
- `GET /open/dict/hy-category` 新增 4 个号源类别（MYH01~04）及涉及的 8 个交易
- `POST /open/02_01_01_08` 医生介绍信息，新增名医类别字段 `MYLB`
- `POST /open/RADTS_YYGH_TZ_TINGZHEN` 停诊通知：号源停诊 → 已约自动退号 → 健康温州消息 + 短信 → 关注者动态
- `POST /open/mingyi-doctor-intro` 【名医医生介绍】查询，入参机构/科室均可不传，出参含名医类别、有无排班

## 演示动线（约 8 分钟）
1. 总入口点公众号菜单「名医温州 → 名医预约」进入居民端，切换「各地名医汇」，进入温医大附一 → 科室 → 点医生头像看资质/坐诊时间
2. 医生页「关注」「分享」（生成带二维码的海报）→「立即预约挂号」选时段 + 留言 → 预约成功（消息 + 短信）
3. 接口服务页发送 `RADTS_YYGH_TZ_TINGZHEN`（或机构端「停诊通知」）→ 居民端消息通知出现停诊、预约记录变为停诊退号
4. 居民端「安排医生」提交需求 → 机构端「名医预约需求」处理 → 居民收到通知
5. 机构端统计查询（按患者姓名“演示”筛选）→ 留言内容导出
6. 管理后台修改「名医汇介绍」→ 居民端首页实时生效；号源池新增号源 → 关注者收到消息

数据：首次启动自动生成到 `data/db.json`（医生、患者均为虚构；身份证号为校验位合法的测试号）。管理后台「平台概览」可一键重置。
